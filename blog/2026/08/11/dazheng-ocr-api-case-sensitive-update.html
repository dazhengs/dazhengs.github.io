5 行代码快速接入 ​

1. 直接传图片文件 (Python requests) ​

python
import requests

API_KEY = "YOUR_API_KEY"
url = f"https://api.dazheng.space/ocr/case-sensitive/file/{API_KEY}"

files = {
    'file': ('image.jpg', open('/path/to/your/image.jpg', 'rb'), 'image/jpeg')
}

response = requests.post(url, files=files)
print(response.json())

2. 传 Base64 字符串 ​

python
import requests
import base64

API_KEY = "YOUR_API_KEY"
url = f"https://api.dazheng.space/ocr/case-sensitive/base64/{API_KEY}"

def image_to_base64(image_path):
    with open(image_path, "rb") as f:
        return base64.b64encode(f.read()).decode('utf-8')

payload = {
    "image_base64": image_to_base64("/path/to/your/image.jpg")
}

response = requests.post(url, json=payload)
print(response.json())
